아래 달력은 예시예요.

설치 방법

다운로드부터 첫 실행까지 5분이면 충분해요. 개인이 만든 테스트 버전이라 처음 열 때만 경고를 한 번 넘겨야 해요.

Mac 다운로드

먼저 확인: 화면 왼쪽 위 Apple 메뉴 → 이 Mac에 관하여에서 칩이 Apple M1 이상, macOS가 14 이상이면 쓸 수 있어요.

  1. 파일 받기위 Mac 다운로드 버튼을 눌러요. CagongBuddy-0.1.zip(약 1.7MB)이 다운로드 폴더에 저장돼요.
  2. 압축 풀기zip을 두 번 클릭하면 CagongBuddy 앱이 나와요.
  3. 응용 프로그램 폴더로 옮기기Finder 왼쪽의 응용 프로그램 폴더로 앱을 끌어다 놓아요.
  4. 처음 열기앱을 두 번 클릭해요. 확인할 수 없다는 경고가 뜨면 휴지통으로 옮기지 말고 완료를 눌러요.
  5. 그래도 열기시스템 설정 → 개인정보 보호 및 보안을 열고 맨 아래쪽 보안 항목에서 그래도 열기를 누른 뒤 암호를 입력해요. 이건 처음 한 번만 하면 돼요.
  6. 사용법 보기켜지면 사용법이 자동으로 열려요. 끝나면 화면 구석의 캐릭터에게 장작을 먹여보세요.
  7. 브라우저 허용유튜브 같은 사이트를 처음 열 때 Chrome이나 Safari 제어를 물어보면 허용을 눌러요. 사이트 제한에 필요한 권한이에요.

자주 묻는 질문

왜 경고가 떠요? 바이러스는 아니에요?

개인이 만든 테스트 앱이라 Apple의 공증(유료 확인 절차)을 받지 않아서 떠요. Apple이 확인하지 못했다는 뜻이지, 바이러스를 찾았다는 뜻은 아니에요. 그래도 이 페이지에서 받은 파일만 여세요.

손상되어 열 수 없다고 나와요

파일을 옮기는 중에 생긴 격리 표시 때문일 수 있어요. 앱을 응용 프로그램 폴더로 옮긴 뒤 터미널에 아래 한 줄을 붙여넣고 다시 열어보세요. 이 페이지에서 받은 파일일 때만 쓰세요.xattr -dr com.apple.quarantine /Applications/CagongBuddy.app

Intel Mac이나 Windows에서도 되나요?

아직 안 돼요. 지금은 Apple 칩(M1 이상)과 macOS 14 이상인 Mac 전용이에요.

켰는데 아무것도 안 보여요

Dock에는 나타나지 않고, 화면 위 메뉴바의 작은 불꽃 아이콘과 화면 구석의 캐릭터로만 보여요. 캐릭터가 없으면 메뉴바 아이콘을 눌러 캐릭터 보이기를 골라요. 메뉴바에 아이콘이 많으면 노치에 가려질 수 있어요.

브라우저 방문 기록을 보는 건가요?

앱이 켜져 있는 동안에는 집중 중이 아니어도 5초마다 켜져 있는 Chrome과 Safari의 현재 탭 주소만 읽어서, 제한한 사이트인지 비교해요. 주소를 저장하거나 어딘가로 보내지 않아요. 앱에 인터넷으로 데이터를 보내는 기능 자체가 없어요.

브라우저 허용을 안 눌렀어요

사이트 제한만 동작하지 않고 나머지는 그대로 쓸 수 있어요. 나중에 켜려면 시스템 설정 → 개인정보 보호 및 보안 → 자동화에서 CagongBuddy 아래의 브라우저를 켜세요.

Arc나 Edge, 웨일에서도 탭을 닫아주나요?

아직은 Chrome과 Safari만 돼요. 다른 브라우저에서는 사이트 제한이 동작하지 않아요.

카페에서 갑자기 소리가 나면 어떡해요?

소리는 연결된 이어폰과 에어팟으로만 나가요. 이어폰이 없으면 소리 대신 캐릭터가 커져서 알려줘요.

집중 기록은 어디에 저장돼요?

이 Mac 안에만 저장돼요. 계정도 없고, 다른 기기와 동기화되지도 않아요.

Mac을 켤 때 자동으로 켜지나요?

자동으로 켜지지 않아요. 원하면 시스템 설정 → 일반 → 로그인 항목에 CagongBuddy를 추가하세요.

노트북을 덮으면 어떻게 돼요?

Mac이 잠들면 집중도 함께 멈추고, 깨어나면 이어서 달릴지 물어봐요.

새 버전은 어떻게 받아요?

자동 업데이트는 없어요. 새 zip을 받아서 앱을 종료한 뒤, 응용 프로그램 폴더의 앱을 새 파일로 바꾸면 돼요. 기록은 그대로 남아요.

끄거나 지우고 싶어요

끄려면 메뉴바 아이콘에서 종료를 눌러요. 지우려면 종료한 뒤 응용 프로그램 폴더의 앱을 휴지통에 넣어요. 기록까지 지우려면 Finder의 폴더로 이동에서 ~/Library/Preferences 를 열고 com.yumin.cagongbuddy.plist 도 지워요.

여기 없는 문제가 생기면 이 페이지를 알려준 사람에게 말해주세요.
