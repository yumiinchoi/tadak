사용 방법

장작을 넣으면,
타닥이가 함께해요.

  1. 1

    장작 넣기

    화면 구석의 타닥이에게 장작을 넣어요.

    집중할 시간을 고르면 몰입이 시작돼요.

  2. 2

    몰입하기

    타닥이를 한 번 누르면 지금까지 집중한 시간을 말풍선으로 알려줘요. 예: 12:34째 집중 중.. (12분 34초째)

    두 번 누르면 진행 창이 열려요. 집중한 시간과 목표 시간, 진행률을 보고 잠깐 쉬거나 포기할 수 있어요.

  3. 325분 달성!

    알림 받기

    집중 시간이 끝나면 진행 창에 ‘25분 달성!’이 떠요. 끝내거나 몇 분 더 달릴 수 있어요.

    따로 만든 알림은 이어폰 소리, 타닥이 확대, 게임 중 고른 방식으로 알려줘요.

사이트 제한

자주 찾는 사이트
사용 시간을 관리해요.

  • 제한한 사이트를 열면 타닥이가 째려봐요.
  • 정한 시간이 끝나기 1분 전에 미리 알려줘요.
  • 시간이 끝나면 5초를 센 뒤 탭을 닫아요.
  • 닫힌 뒤 쉬는 시간 동안 다시 열면 5초 뒤 다시 닫아요.

유튜브와 인스타그램이 기본으로 들어 있어요. 다른 사이트는 링크를 붙여넣어 추가해요. 사용 시간과 쉬는 시간은 설정의 닫기까지, 다시 열기까지에서 정해요. Chrome과 Safari에서 동작하고, 브라우저 제어를 허용해야 해요.

이어폰 소리

알림 소리는 연결한 이어폰에서만 들려요. 소리가 나갈 이어폰은 설정에서 골라요.

타닥이 확대

이어폰이 연결되지 않으면 타닥이가 커져서 알려줘요. 설정에서 커지기를 켜면 이어폰이 있어도 커져요.

    브라우저 제어 허용 사이트 제한을 처음 쓸 때

FAQ

자주 묻는 질문

설치와 실행

왜 보안 경고가 뜨나요? 안전한 앱인가요?

개인이 만든 테스트 앱이라 Apple의 공증(유료 확인 절차)을 받지 않아서 떠요. Apple이 확인하지 못했다는 뜻이지, 바이러스를 찾았다는 뜻은 아니에요. 그래도 이 페이지에서 받은 파일만 여세요.

“손상되어 열 수 없습니다”라고 나와요.

파일을 옮기는 중에 생긴 격리 표시 때문일 수 있어요. 앱을 응용 프로그램 폴더로 옮긴 뒤 터미널에 아래 한 줄을 붙여넣고 다시 열어보세요. 이 페이지에서 받은 파일일 때만 쓰세요.xattr -dr com.apple.quarantine /Applications/Tadak.app

앱을 켰는데 타닥이가 보이지 않아요.

Dock에는 나타나지 않고, 화면 위 메뉴바의 작은 불꽃 아이콘과 화면 구석의 타닥이로만 보여요. 타닥이가 없으면 메뉴바 아이콘을 눌러 캐릭터 보이기를 골라요. 메뉴바에 아이콘이 많으면 노치에 가려질 수 있어요.

새 버전은 어떻게 받나요?

자동 업데이트는 없어요. 새 zip을 받아서 앱을 종료한 뒤, 응용 프로그램 폴더의 앱을 새 파일로 바꾸면 돼요. 기록은 그대로 남아요.

타닥이를 종료하거나 삭제하고 싶어요.

끄려면 메뉴바 아이콘에서 종료를 눌러요. 지우려면 종료한 뒤 응용 프로그램 폴더의 앱을 휴지통에 넣어요. 기록까지 지우려면 Finder의 폴더로 이동에서 ~/Library/Preferences 를 열고 com.yumin.cagongbuddy.plist 도 지워요.

브라우저와 사이트 제한

브라우저 방문 기록을 확인하나요?

앱이 켜져 있는 동안에는 집중 중이 아니어도 5초마다 켜져 있는 Chrome과 Safari의 현재 탭 주소만 읽어서, 제한한 사이트인지 비교해요. 주소를 저장하거나 어딘가로 보내지 않아요. 앱에 인터넷으로 데이터를 보내는 기능 자체가 없어요.

브라우저 제어를 허용하지 않았어요.

사이트 제한만 동작하지 않고 나머지는 그대로 쓸 수 있어요. 나중에 켜려면 시스템 설정 → 개인정보 보호 및 보안 → 자동화에서 Tadak 아래의 브라우저를 켜세요.

Arc, Edge, 웨일에서도 탭을 닫을 수 있나요?

아직은 Chrome과 Safari만 돼요. 다른 브라우저에서는 사이트 제한이 동작하지 않아요.

알림과 기록

카페에서 갑자기 소리가 나면 어떡하죠?

소리는 연결된 이어폰과 에어팟으로만 나가요. 이어폰이 없으면 소리 대신 타닥이가 커져서 알려줘요.

집중 기록은 어디에 저장되나요?

이 Mac 안에만 저장돼요. 계정도 없고, 다른 기기와 동기화되지도 않아요.

Mac을 켤 때 타닥이도 자동으로 켜지나요?

자동으로 켜지지 않아요. 원하면 시스템 설정 → 일반 → 로그인 항목에 Tadak을 추가하세요.

노트북 덮개를 닫으면 어떻게 되나요?

Mac이 잠들면 집중도 함께 멈추고, 깨어나면 이어서 달릴지 물어봐요.
